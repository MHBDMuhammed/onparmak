# Destek

Onparmak gönüllü olarak sürdürülen açık kaynak bir projedir. Bire bir kullanım desteği veya yanıt süresi garantisi yoktur; iyi hazırlanmış raporlar mümkün olduğunda incelenir.

## Yardım almadan önce

1. Güncel canlı sürümde veya güncel `main` branch'inde tekrar deneyin.
2. Fiziksel klavye düzeninizin Türkçe Q olduğunu doğrulayın.
3. Tarayıcı konsolunda hata varsa kişisel veri içermeyen kısmını kaydedin.
4. Mevcut issue'larda aynı problemi arayın.

## Doğru kanal

- Tekrarlanabilir ürün veya kurulum hatası: [Bug report](https://github.com/MHBDMuhammed/onparmak/issues/new?template=bug.yml)
- Kullanıcı problemiyle başlayan ürün önerisi: [Feature request](https://github.com/MHBDMuhammed/onparmak/issues/new?template=feature.yml)
- Güvenlik açığı: [Private vulnerability report](https://github.com/MHBDMuhammed/onparmak/security/advisories/new)

GitHub Issues genel on parmak eğitimi danışmanlığı, kişisel yazma performansı değerlendirmesi veya üçüncü taraf hosting desteği için kullanılmaz.

## Yerel veriler

Onparmak hesabı veya sunucu yedeği tutmaz. Tarayıcı verisi silindiyse ve daha önce Ayarlar bölümünden JSON yedeği indirilmediyse ilerleme geri getirilemez. Yedek dosyanızı issue'ya eklemeyin; kullanıcı adı ve ayrıntılı çalışma geçmişi içerebilir.
